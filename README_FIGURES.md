# Система персоналий (Видатні діячі)

## Описание

Система для управления персоналиями (выдающимися деятелями) с функциями:
- Полный CRUD (создание, чтение, обновление, удаление)
- Алфавитное разбиение по первым буквам фамилий
- Автоматические ссылки на персоналии в текстовом контенте
- Загрузка изображений персоналий

## Использование

### Публичная часть

1. **Список персоналий**: `/figures`
   - Отображение всех персоналий с алфавитным разбиением
   - Фильтрация по буквам алфавита
   - Карточки с краткой информацией и ссылками на детали

2. **Детальная страница персоналии**: `/figures/{id}`
   - Полная информация о персоналии
   - Изображение и биография
   - Возврат к списку

### Административная часть

Доступна по адресу `/admin/figures` (требует авторизации):

1. **Список персоналий**: `/admin/figures`
   - Таблица со всеми персоналиями
   - Действия: просмотр, редактирование, удаление
   - Пагинация

2. **Добавление персоналии**: `/admin/figures/create`
   - Форма с полями: имя, биография, изображение
   - Валидация данных
   - Автоматическое определение первой буквы

3. **Редактирование персоналии**: `/admin/figures/{id}/edit`
   - Предзаполненная форма
   - Возможность изменения изображения
   - Сохранение изменений

## Автоматические ссылки

### В представлениях (Blade)

```blade
{{-- Для обычного текста --}}
{!! @figureLinks($text) !!}

{{-- Для HTML контента --}}
{!! @figureLinksByHtml($htmlContent) !!}

{{-- Использование компонента --}}
<x-figure-links-example :content="$text" :is-html="false" />
```

### В моделях

Используйте accessor `processed_content` для автоматической обработки:

```php
// В BlockElement, TheoryBlock и других моделях
$element->processed_content; // Возвращает контент с автоматическими ссылками
```

### Программно

```php
use App\Services\FigureLinkService;

$service = app(FigureLinkService::class);

// Для обычного текста
$processedText = $service->processText($text);

// Для HTML
$processedHtml = $service->processHtml($html);

// Helper-функции
$processedText = process_figure_links($text);
$processedHtml = process_figure_links($html, true);
```

## Структура базы данных

Таблица `figures`:
- `id` - первичный ключ
- `name` - имя персоналии (индексируется)
- `biography` - биография (текст)
- `image_path` - путь к изображению (nullable)
- `first_letter` - первая буква имени (вычисляемое поле, индексируется)
- `created_at`, `updated_at` - временные метки

## Маршруты

### Публичные
- `GET /figures` - список персоналий
- `GET /figures/{figure}` - детальная страница

### Административные
- `GET /admin/figures` - список для управления
- `GET /admin/figures/create` - форма создания
- `POST /admin/figures` - сохранение новой персоналии
- `GET /admin/figures/{figure}/edit` - форма редактирования
- `PUT /admin/figures/{figure}` - обновление персоналии
- `DELETE /admin/figures/{figure}` - удаление персоналии

## Настройка

1. Выполните миграции:
```bash
php artisan migrate
```

2. Создайте симлинк для хранилища:
```bash
php artisan storage:link
```

3. Убедитесь, что папка `storage/app/public/figures` имеет права на запись.

## Стилизация

Для ссылок на персоналии используется CSS-класс `figure-link`. Настройте стили в зависимости от дизайна:

```css
.figure-link {
    color: #2563eb;
    text-decoration: underline;
    text-decoration-style: dotted;
}

.figure-link:hover {
    text-decoration-style: solid;
}
```

## Безопасность

- Все загруженные изображения проходят валидацию типа и размера
- HTML контент экранируется при обработке ссылок
- Административная часть защищена middleware авторизации
- Удаление персоналии требует подтверждения
