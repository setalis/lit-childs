# Гнучка система автоматичних посилань

## Огляд

Система автоматичних посилань була значно покращена для підтримки різних відмінків української мови та ігнорування регістру. Тепер система може автоматично створювати посилання на персоналії та терміни незалежно від того, в якому відмінку вони знаходяться в тексті, **зберігаючи оригінальний текст незмінним**.

## Основні покращення

### 1. Підтримка відмінків української мови

Система автоматично розпізнає та обробляє слова в різних відмінках:

- **Називний** (ім'я): Шевченко, література
- **Родовий** (кого? чого?): Шевченка, літератури
- **Давальний** (кому? чому?): Шевченку, літературі
- **Знахідний** (кого? що?): Шевченка, літературу
- **Орудний** (ким? чим?): Шевченком, літературою
- **Місцевий** (на кому? на чому?): Шевченку, літературі
- **Кличний** (звертання): Шевченку, літературо

### 2. Ігнорування регістру

Система працює незалежно від регістру літер:
- `Шевченко` = `шевченко` = `ШЕВЧЕНКО`

### 3. Збереження оригінального тексту

**Важливо**: Система НЕ змінює оригінальний текст на сторінці. Вона створює посилання з оригінальним текстом як є.

## Використання

### В Blade шаблонах

```blade
{{-- Для звичайного тексту --}}
{!! process_figure_links($text) !!}

{{-- Для HTML контенту --}}
{!! process_figure_links($htmlContent, true) !!}

{{-- Використання accessor в моделях --}}
{!! $element->processed_content !!}
```

### В контролерах

```php
use App\Services\FigureLinkService;

$service = app(FigureLinkService::class);

// Обробка звичайного тексту
$processedText = $service->processText($text);

// Обробка HTML
$processedHtml = $service->processHtml($html);
```

### В моделях

```php
// В моделі BlockElement
$element->processed_content; // Автоматично оброблений контент з посиланнями
```

## Приклади роботи

### Персоналії

**Вхідний текст:**
```
Творчість Тараса Шевченка справила вплив. Про Шевченка говорять. 
Шевченком захоплюються читачі. До Шевченка звертаються дослідники.
```

**Результат:**
```
Творчість Тараса <a href="/figures/1" class="figure-link">Шевченка</a> справила вплив. 
Про <a href="/figures/1" class="figure-link">Шевченка</a> говорять. 
<a href="/figures/1" class="figure-link">Шевченком</a> захоплюються читачі. 
До <a href="/figures/1" class="figure-link">Шевченка</a> звертаються дослідники.
```

**Зверніть увагу**: Оригінальний текст "Шевченка", "Шевченком" залишається незмінним в посиланнях.

### Терміни

**Вхідний текст:**
```
Література є важливою частиною культури. Про літературу говорять у школах. 
Літературою захоплюються молоді люди.
```

**Результат:**
```
<a href="/terms/1" class="term-link">Література</a> є важливою частиною культури. 
Про <a href="/terms/1" class="term-link">літературу</a> говорять у школах. 
<a href="/terms/1" class="term-link">Літературою</a> захоплюються молоді люди.
```

### Регістр

**Вхідний текст:**
```
ШЕВЧЕНКО був великим поетом. шевченко писав вірші. Шевченко створив багато творів.
```

**Результат:**
```
<a href="/figures/1" class="figure-link">ШЕВЧЕНКО</a> був великим поетом. 
<a href="/figures/1" class="figure-link">шевченко</a> писав вірші. 
<a href="/figures/1" class="figure-link">Шевченко</a> створив багато творів.
```

**Зверніть увагу**: Оригінальний регістр зберігається в посиланнях.

## Тестування

### Через веб-інтерфейс

Відвідайте сторінку `/test/flexible-links` для інтерактивного тестування системи.

### Через консольні команди

```bash
# Запуск стандартних тестів

# Тестування конкретного слова

# Тестування конкретного тексту

```

## Технічна реалізація

### Основні методи

1. **`generateWordVariants()`** - генерує варіанти слова з різними закінченнями для пошуку
2. **`getBaseForm()`** - визначає базову форму слова
3. **`getDeclensionVariants()`** - створює варіанти склонення
4. **`createFlexiblePattern()`** - створює regex паттерн для пошуку
5. **`processText()`** - обробляє текст зі збереженням оригінального тексту
6. **`processHtml()`** - обробляє HTML зі збереженням оригінального тексту

### Алгоритм роботи

1. Отримання списку персоналій та термінів з бази даних
2. Для кожного слова:
   - Генерація варіантів з різними закінченнями для пошуку
   - Створення regex паттерну з ігноруванням регістру
   - Використання `preg_replace_callback` для збереження оригінального тексту
   - Заміна першого входження в тексті
3. Безпечна обробка HTML контенту (без заміни в тегах)

### Підтримувані закінчення

Система підтримує всі типові закінчення української мови:

- Односложні: а, я, о, е, и, у, ю, ь, і, ї
- Двусложні: ого, ому, им, ою, их, ими
- Трехсложні: ого, ому, им, ою, их, ими
- Специфічні для імен: ка, ко, ку, ком, ці

## Налаштування

### Додавання нових закінчень

Для додавання нових закінчень відредагуйте масив `$endings` в методі `getBaseForm()`:

```php
private function getBaseForm(string $word): string
{
    $endings = [
        // Додайте нові закінчення тут
        'нове_закінчення',
        // ...
    ];
    // ...
}
```

### Налаштування стилів

Стилі для посилань можна налаштувати в CSS:

```css
.figure-link {
    color: #2563eb;
    text-decoration: underline;
    text-decoration-style: dotted;
}

.figure-link:hover {
    color: #1d4ed8;
    text-decoration-style: solid;
}

.term-link {
    color: #059669;
    text-decoration: underline;
    text-decoration-style: dotted;
}

.term-link:hover {
    color: #047857;
    text-decoration-style: solid;
}
```

## Обмеження

1. **Перше входження**: Система замінює тільки перше входження слова в тексті
2. **Границі слів**: Пошук здійснюється тільки в межах слів (з використанням `\b`)
3. **HTML безпека**: Система не замінює слова всередині HTML тегів
4. **Продуктивність**: При великій кількості персоналій/термінів може вплинути на швидкість

## Майбутні покращення

1. **Морфологічний аналіз**: Інтеграція з бібліотеками морфологічного аналізу
2. **Кешування**: Кешування результатів обробки
3. **Налаштування**: Можливість налаштування кількості замін
4. **Статистика**: Відстеження статистики використання посилань
