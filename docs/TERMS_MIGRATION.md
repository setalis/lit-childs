# Миграция терминов на новую структуру с множественными толкованиями

## Описание изменений

Система терминов была обновлена для поддержки множественных толкований с собственными источниками информации. Теперь каждый термин может иметь несколько определений, каждое со своим источником.

## Структура базы данных

### Новая таблица: `term_definitions`
- `id` - уникальный идентификатор
- `term_id` - внешний ключ к таблице `terms`
- `definition` - текст толкования
- `source` - источник информации (опционально)
- `sort_order` - порядок сортировки
- `created_at`, `updated_at` - временные метки

### Обновленная таблица: `terms`
- Удалена колонка `definition` (данные перенесены в `term_definitions`)
- Сохранены колонки `name`, `image_path`, `first_letter`

## Порядок миграции

### 1. Запуск миграций
```bash
php artisan migrate
```

### 2. Миграция данных (если необходимо)
```bash
php artisan terms:migrate-to-definitions
```

### 3. Проверка данных
Убедитесь, что все термины имеют толкования в новой таблице.

## Использование

### Создание термина с множественными толкованиями
```php
$term = Term::create([
    'name' => 'Автор',
    'image_path' => 'path/to/image.jpg'
]);

$term->definitions()->createMany([
    [
        'definition' => 'Автор – це фізична особа, творчою працею якої створено твір.',
        'source' => 'Літературознавчий словник-довідник, 2-е вид., випр. і доп. / Р.Т. Громʼяк, Ю.І. Ковалів та ін. Київ : ВЦ "Академія", 2006. 752 с.',
        'sort_order' => 0
    ],
    [
        'definition' => 'Автор – той, хто створив твір; іноді автор присутній у творі як ліричний герой...',
        'source' => 'Моклиця М. Вступ до літературознавства : посібник для студентів філологічних факультетів. Луцьк, 2011. 467 с.',
        'sort_order' => 1
    ]
]);
```

### Получение толкований
```php
$term = Term::with('definitions')->find(1);

foreach ($term->definitions as $definition) {
    echo $definition->definition;
    if ($definition->source) {
        echo "Джерело: " . $definition->source;
    }
}
```

## Обратная совместимость

Для обратной совместимости сохранен атрибут `definition`, который возвращает первое толкование:
```php
$term->definition; // Первое толкование
$term->definitions; // Все толкования
```

## Обновленные представления

- `admin/terms/create.blade.php` - форма создания с поддержкой множественных толкований
- `admin/terms/edit.blade.php` - форма редактирования
- `pages/terms/show.blade.php` - отображение всех толкований
- `pages/dictionary/index.blade.php` - краткий обзор с указанием количества толкований

## JavaScript функциональность

Формы создания и редактирования поддерживают динамическое добавление/удаление толкований:
- `addDefinition()` - добавление нового толкования
- `removeDefinition(button)` - удаление толкования

## Валидация

- Обязательно минимум одно толкование
- Каждое толкование обязательно
- Источник опциональный
- Поддержка загрузки изображений
